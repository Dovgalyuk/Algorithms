Разработать программный интерфейс модуля (заголовки функций) библиотеки LibraryCPPTemplate для работы с ориентированными графами. Граф должен инициализироваться количеством вершин или размерностью сетки.
Параметры шаблона графа --- это типы пометок для рёбер и для вершин.
В интерфейсе должна быть поддержка следующих операций: добавить вершину (или изменить размерность), добавить ребро (между заданными вершинами), удалить вершину, удалить ребро (если применимо), проверить существует ли ребро между вершинами, задать/считать пометку для ребра, задать/считать пометку для вершины,
получить пометки всех вершин в виде вектора, прочитать граф из потока ввода.
Должна быть реализована структура-итератор для поддержки перебора всех соседей заданной вершины.
Реализовать в библиотеке Library модуль поддержки графов с разработанным интерфейсом. Связи должны храниться в виде матрицы смежности в контейнере Vector библиотеки LibraryCPPTemplate.
Разработать и добавить в проект LibraryCPPTemplate программу, тестирующую работу библиотеки для графа.
Добавить в решение проект, использующий графы. Программа должна считывать параметры графа и искать для него алгоритмом Форда-Фалкерсона максимальный поток между заданными вершинами.
Добавить примеры входных данных и описать тесты в CMakeLists.txt, которые запускают разработанную программу и используют входные данные.
Вершины должны обозначаться строковыми названиями.
