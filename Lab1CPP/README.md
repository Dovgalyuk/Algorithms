# Лабораторная работа 1 (C++)

В этой папке лежат две программы, которые используют контейнер `Array`
из библиотеки `LibraryCPP`.

## Задача 1

Файл `task1.cpp`.

Входной файл имеет такой формат:

    5
    1 2 3 4 5
    0 4

Первая строка - размер массива `n`. Вторая строка - `n` целых чисел.
Третья строка - номера `k1` и `k2` (нумерация элементов с нуля).

Из всех положительных элементов вычитается элемент `k1`,
из остальных - элемент `k2`. Результат выводится на экран.

## Задача 2

Файл `task2.cpp`.

Входной файл имеет такой формат:

    6
    1 2 3 4 5 6
    2 4

Первая строка - размер массива `n`. Вторая строка - `n` целых чисел.
Третья строка - границы интервала `a` и `b`.

Все элементы, которые попадают в интервал `[a, b]`, удаляются.
Свободные места в конце массива заполняются нулями.
Результат выводится на экран.

## Сборка и запуск

Из корневой папки проекта:

    mkdir build
    cd build
    cmake ..
    cmake --build .

Запуск программы (имя файла можно посмотреть в папке `tests`):

    Lab1CPP_Task1 ../Lab1CPP/tests/task1_1.txt
    Lab1CPP_Task2 ../Lab1CPP/tests/task2_1.txt

## Тесты

Тесты описаны в `CMakeLists.txt`. Для каждого примера входных данных
проверяется строка, которую выводит программа.

Запуск всех тестов:

    ctest --output-on-failure
