# Лабораторная работа 2: JollyScript

Интерпретатор языка [JollyScript](https://esolangs.org/wiki/JollyScript).
Используется функциональный вариант библиотеки C++ — `LibraryCPP`.

## Сборка и запуск

Из корня репозитория:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build
ctest --test-dir build --output-on-failure
./build/Lab2CPP/JollyScript Lab2CPP/test_data/hello_world.jolly Lab2CPP/test_data/hello_world.input
```

Программа принимает ровно два аргумента: путь к скрипту и путь к файлу
входных данных. Для скрипта без чтения данных второй файл должен быть пустым.
Результат записывается в stdout, сообщения об ошибках — в stderr.
Пример из задания выводит `Hello World!` без дополнительного перевода строки.

## Реализация

В `LibraryCPP/list.cpp` реализован односвязный список целых чисел с указателями
на первый и последний узлы. Вставка в начало или после узла и удаление первого
или следующего узла выполняются за O(1). Указатель на последний узел обновляется
при вставке и удалении. Узлы удаляются последовательно, без рекурсии.
`list_item_prev` возвращает `nullptr`: обратных ссылок в односвязном списке нет.
Узлы, передаваемые в операции вставки и удаления, должны принадлежать этому списку.

`LibraryCPP/stack.cpp` использует только операции списка. Вершина стека — первый
узел; push, pop, get и проверка пустоты выполняются за O(1). Фиксированного
ограничения размера нет. Чтение и удаление из пустого стека вызывают
`std::out_of_range`.

В `jollyscript.cpp` создаются два стека библиотеки:

- стек данных хранит числа от 0 до 15;
- стек отложенных ветвей хранит тройки целых чисел: столбец, строка, направление.

Курсор начинает движение от единственного `*` в первой строке, вниз и влево.
На `^` правая ветвь откладывается в стек, а левая выполняется сразу. На `~`
выполнение продолжается с последней отложенной ветви. Стек данных, режим печати
и адрес возврата общие для всех ветвей. Рекурсия для исполнения не используется.

Поддерживаются все команды спецификации: `* / \ ^ ~ + - : % $ ?`,
цифры `0–9 A–F`, `. # " n , & { }`. Арифметика выполняется по модулю 16.
`.` и `,` не удаляют значения; в паре полубайтов младший лежит на вершине.
`#` читает ровно один символ, не пропуская пробелы. В конце входа `#` кладёт
один ноль, `&` — два нуля. Возврат `}` сохраняет текущее направление и снова
выполняет команду по адресу `{`. Неизвестные символы игнорируются, а в режиме
печати любой символ, кроме переключателя `"`, выводится буквально.

Скрипт читается как сетка байтов; пробелы сохраняются, окончания строк LF и CRLF
поддерживаются. Вход для `&` также читается побайтно, включая нулевой байт.
Геометрия ёлки не проверяется отдельно: каждая посещённая координата должна
существовать в файле. Случаи, которые спецификация оставляет неопределёнными
(недостаток данных, неверный hex, неверный старт, выход за сетку, возврат до `{`),
завершаются с кодом 1 и диагностикой. Корректные бесконечные программы могут
работать бесконечно; ограничение времени установлено только для тестов CMake.

## Тесты

Исходные тесты `LibraryCPP/Tests/list.cpp` и `stack.cpp` включены без изменения.
Дополнительный `TestLab2Containers` проверяет пустые контейнеры, вставку и
удаление узлов, обновление конца списка, повторное использование стека,
порядок 100000 элементов и освобождение непустых контейнеров.

В `CMakeLists.txt` описаны тесты интерпретатора с двумя входными файлами.
`cmake/RunAndCompare.cmake` проверяет код завершения, stderr и точное совпадение
stdout с файлом `.expected`:

- `hello_world`: пример преподавателя;
- `arithmetic`: переполнение, вычитание, swap, duplicate и discard;
- `hex_input`: чтение hex, повторный вывод вершины и EOF;
- `byte_input`, `binary_input`: порядок полубайтов, сохранение значений после
  вывода, EOF, нулевой байт и байты с установленным старшим битом;
- `printing`, `comments`: режим печати и игнорируемые символы;
- `branches`: вложенные ветви, порядок выполнения и общий стек данных;
- `condition_0`, `condition_3`: обе ветви `?` и декремент;
- `directions`, `return_loop`: смена направления и цикл с `{` / `}`;
- `cat`, `cat_empty`: копирование текста и завершение на EOF;
- `crlf`: окончания строк Windows;
- остальные тесты проверяют диагностику ошибочных скриптов и входных данных.
